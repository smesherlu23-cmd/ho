# Whatever

Веб-приложение для создания диаграмм и совместной работы в реальном времени. Наброски от руки
превращаются в ровные фигуры, изменения участников видны сразу, доска работает и без сети.
Разворачивается на собственном сервере.

## Запуск на сервере

Нужны Linux и Docker с плагином Compose.

```bash
cp .env.example .env              # задайте POSTGRES_PASSWORD
docker compose up -d --build
```

Приложение откроется на порту 8080 (меняется настройкой `WHATEVER_PORT`). Миграции базы
применяются автоматически перед стартом бэкенда. Проверка: `curl http://localhost:8080/api/health`.

Первого администратора создаёт команда на сервере, пароль она спросит дважды. Остальные
учётные записи администратор создаёт в разделе «Пользователи».

```bash
docker compose exec backend python -m app.cli create-admin admin --name "Иван Иванов"
```

HTTPS, обновление, резервное копирование и восстановление описаны в [docs/operations.md](docs/operations.md).

## Настройки

Все настройки задаются в файле `.env` в корне репозитория. Полный список с пояснениями
и значениями по умолчанию — в [.env.example](.env.example); обязателен только `POSTGRES_PASSWORD`.
Бэкенд читает настройки в одном месте, `backend/app/core/config.py`, и проверяет их при запуске:
ошибка в значении остановит его с понятным сообщением, а не проявится позже.

Чаще всего меняют:

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `POSTGRES_PASSWORD` | — | пароль базы данных |
| `WHATEVER_PORT` | `8080` | порт приложения на сервере |
| `WHATEVER_BIND_ADDRESS` | `0.0.0.0` | `127.0.0.1`, если перед приложением прокси с TLS на том же сервере |
| `WHATEVER_COOKIE_SECURE` | `false` | `true`, если приложение открывают по HTTPS |
| `WHATEVER_SESSION_TTL_DAYS` | `30` | сколько дней действует вход |
| `WHATEVER_LOG_FORMAT` | `text` | `json` для сборщиков журналов |

## Разработка

```bash
make install     # зависимости и .env из примера
make db          # PostgreSQL в Docker на localhost:5432
make backend     # http://localhost:8000, перезапуск при правке кода
make frontend    # http://localhost:5173
make check       # все проверки, как в CI
```

Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).

| Часть | Папка | Стек |
| --- | --- | --- |
| Фронтенд | `frontend/` | TypeScript, React, Vite, Canvas 2D, Yjs |
| Бэкенд | `backend/` | Python 3.12, FastAPI, SQLAlchemy (async), Alembic, pycrdt |
| Данные | — | PostgreSQL 16 |
